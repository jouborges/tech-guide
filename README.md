# Tech Guide | Data Science & Analytics

Meu laboratório de estudos, experimentação e desenvolvimento de projetos em Ciência de Dados.

Este repositório documenta minha evolução técnica, desde os fundamentos de programação e análise de dados até a construção de soluções utilizando estatística, Machine Learning e engenharia de dados.

## 🎯 Objetivo

Desenvolver autonomia para investigar problemas, trabalhar com dados reais, construir modelos analíticos e comunicar resultados de maneira clara.

O foco não é apenas aprender ferramentas, mas compreender os problemas e desenvolver soluções próprias.

## 🛠️ Tecnologias

**Principais áreas de estudo:**

- Python: pandas, NumPy e Jupyter
- SQL: consultas, modelagem e análise de dados
- Estatística: análise exploratória, distribuições e inferência
- Machine Learning: classificação, regressão e avaliação de modelos

**Tecnologias complementares:**

- R
- Git e GitHub
- Power BI
- Ferramentas de engenharia de dados

## 🔎 Metodologia

Cada projeto será desenvolvido em etapas:

1. Definição do problema
2. Coleta e compreensão dos dados
3. Limpeza e tratamento
4. Análise exploratória
5. Investigação estatística
6. Modelagem, quando aplicável
7. Avaliação dos resultados
8. Documentação e conclusões

Os projetos utilizarão dados públicos, sintéticos ou devidamente autorizados.

## 📈 Evolução

Este repositório está em desenvolvimento contínuo.
